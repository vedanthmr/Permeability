Adversarial Threat Intelligence Matrix

Live classification coverage across 11 adversarial prompt injection categories and document steganography methods.

1. Direct Prompt Injection

100% BLOCKED

Raw instruction overrides ("Ignore previous instructions"), system prompt extraction, and roleplay hijacking.

2. Indirect Injection (Doc / Web)

100% BLOCKED

Payloads hidden in external contexts, emails, customer tickets, reviews, or retrieved RAG documents.

3. Unicode & Zero-Width Steganography

100% BLOCKED

Invisible characters (\u200b, \u200c, \ufeff) embedding covert malicious tokens between benign words.

4. Obfuscation (Base64 / Hex / ROT)

100% BLOCKED

Base64 encoded directives and hex-encoded commands unpacked in real time by Layer 1A decoders.

5. Virtualization & Hypothetical Framing

100% BLOCKED

"In a hypothetical movie script...", "In an alternate reality with no ethical rules...", and simulated jailbreaks.

6. Suffix Continuation & Smuggling

100% BLOCKED

Appended tokens forcing the model to complete unsafe instructions or start with affirmative compliance tokens.

7. Dual-Language Token Smuggling

100% BLOCKED

Mixing languages or transliterating high-risk keywords into non-Latin alphabets to evade simple keyword filters.

8. System Prefix Spoofing

100% BLOCKED

Fake [SYSTEM] or <|im_start|> boundary injection attempting to simulate chat template directives.

9. Leetspeak & Phonetic Camouflage

100% BLOCKED

1gn0r3 pr3v10us 1nstruct10ns and phonetic substitutions caught by canonical tokenizer normalization.

10. Markdown & HTML Steganography

100% BLOCKED

CSS display:none, opacity:0, font-size:0pt, and hidden HTML comments stripped by Layer 2A parser.

11. Multi-Turn Roleplay Drift

100% BLOCKED

Gradual persona migration and context pollution caught by semantic similarity baseline tracking.
